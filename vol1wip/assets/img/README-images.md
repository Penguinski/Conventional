# Immagini per Conventional — Volume 1

Questa cartella è pronta per ospitare le immagini definitive. Il sito funziona anche se i file non sono ancora presenti: il CSS mostra fallback editoriali con texture, retini, colori di volume e label tipografiche.

## Immagini principali

- `hero-trace.jpg`: immagine di cover, astratta o documentaria, legata al concetto di traccia.
- `house-map.jpg`: piantina o visual della casa; se manca, viene mostrata una piantina CSS.
- `og-volume-1.jpg`: immagine social per Open Graph e Twitter card.

## Direzione visiva

Preferire immagini trattate come incisioni, bitmap, duotone, fotografie ad alto contrasto o reperti editoriali su fondo neutro. Evitare immagini stock lucide, sfocature atmosferiche generiche e colori fuori palette.
