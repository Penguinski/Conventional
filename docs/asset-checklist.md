# Asset checklist

La build usa illustrazioni provvisorie in CSS, deliberatamente semplici e sostituibili senza cambiare la logica.

- Wordmark vettoriale definitivo di Conventional.
- Illustrazione affollata finale per `Trova l’intruso`, con personaggio ricorrente originale.
- Set di almeno 25 oggetti illustrati per `Il cassetto disordinato`.
- Coppia di scene finali sincronizzate per `Prima / Dopo`.
- Due vignette editoriali finali.
- Timbri `COMPLETATO` e `ARCHIVIO` definitivi.
- Texture seamless di carta compressa, se quella procedurale non viene approvata.
- Immagine Open Graph finale dopo approvazione visiva della home.

I font Source Serif 4, Lisu Bosa e DM Mono sono già ospitati localmente tramite i pacchetti Fontsource.
